### • Features [Including Gabriel's mods]
 - KernelSU-Next supported with SUSFS.
 - Enabled support for Dex TouchPad.
 - Force fingerprint position to 1.
 - Disabled Knox securities (as useless after unlocking bootloader, instead spams on logs).
 - Updated SDFAT drivers to get SDCard working in OneUI7 based ROMs.
 - Unlocked 2210MHz for CPU (Basically overclock).
 - Backported rtl8xxxu from Linux Kernel 6.6.y
 - Fix fixed channel -1 in mac80211
 - Fully open-source with clean commits.
 - and so on..
